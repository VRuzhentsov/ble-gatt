## Default Permission

Default permissions for the ble-gatt plugin: capability query, advertise/scan, and GATT client/server operations.

#### This default permission set includes the following:

- `allow-ble-capabilities`
- `allow-ble-advertise`
- `allow-ble-stop-advertising`
- `allow-ble-notify`
- `allow-ble-scan-once`
- `allow-ble-connect`
- `allow-ble-read`
- `allow-ble-write`
- `allow-ble-disconnect`
- `allow-ble-connection-mtu`
- `allow-ble-watch-events`
- `allow-ble-unwatch-events`
